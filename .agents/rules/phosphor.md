# Phosphor Icons Rule

When importing icons from `@phosphor-icons/react` or `@phosphor-icons/react/dist/ssr`:
- Always use the `*Icon` suffix (e.g. `CircleNotchIcon`, `LockSimpleIcon`, `EyeIcon`, `SignOutIcon`, `WalletIcon`).
- Importing without the `Icon` suffix (e.g. `CircleNotch`, `LockSimple`) is deprecated in `@phosphor-icons/react` v2.1+.
